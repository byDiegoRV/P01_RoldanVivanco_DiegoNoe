# P09: guía de reproducción (Xochitl)

## Entorno
- Windows, Git Bash en VS Code.
- Java 11 y Maven 3.9 
- PostgreSQL 16 con Docker (`docker compose up -d`), puerto 5435.

## Pasos desde un clon limpio
1. `git checkout master && git pull origin master` y `git checkout -b feature/p09-xochitl`.
2. Copiar `.env.example` a `.env` y poner la contraseña local.
3. `docker compose up -d`.
4. `set -a; source .env; set +a` y `mvn clean test`: 142 pruebas, 0 fallos, BUILD SUCCESS.
5. `./scripts/verify-module.sh M12`: MODULO_M12_VERIFICADO.

## Registro de errores
1. **connection refused en 5435:** el contenedor de PostgreSQL no estaba levantado. Se resolvió con `docker compose up -d`.
2. **password authentication failed:** la contraseña del contenedor no coincidía con la del `.env`. Se resolvió con `ALTER USER` y recreando el contenedor con `docker compose down -v` y `up -d`.
3. **`curl` en PowerShell fallaba (SessionVariable):** en PowerShell `curl` es un alias de `Invoke-WebRequest`. Se resolvió usando Git Bash.
4. **`curl -s` sin salida:** la API estaba apagada; con `-s` curl no muestra el error de conexión.
