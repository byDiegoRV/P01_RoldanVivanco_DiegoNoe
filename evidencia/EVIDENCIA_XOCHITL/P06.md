## 2. Desarrollo de Pruebas Unitarias

Se integraron y validaron casos de prueba en `VentaTest.java`:

### A. Caso de Éxito 
- **Método:** `testTotalFormateado()`
- **Descripción:** Valida que al agregar productos con precio y cantidad específicos, el total formateado coincida exactamente con el cálculo esperado.

### B. Caso de Error / Límite (Patrón Factory)
- **Método:** `testPagoFactory_MetodoInexistente_LanzaExcepcion()`
- **Descripción:** Se probó el envío de una clave de método de pago no soportada (`"PAYPAL_NO_SOPORTADO"`).
- **Resultado Esperado:** Se valida mediante `assertThrows` que la fábrica `PagoFactory` intercepte el valor inválido y lance una excepción de tipo `IllegalArgumentException`.
